# Project documentation

Start with [RUN_PROJECT.md](RUN_PROJECT.md) for the current TensorFlow/Keras setup, required files and commands. The project uses one root .venv and one requirements.txt.

- [Training guide](../Training/README.md): model files, settings and output folders.
- [Work log](WORK_LOG.md): chronological changes and experiments; historical entries are not current setup instructions.
- about_dataset.docx and about_training.docx: earlier study/viva material. They have not been fully revised for every later implementation change; use current code and RUN_PROJECT.md for operational details.
- [Preprocessing preview](../Preprocessing/PREPROCESSING_PREVIEW.png): a saved example of the preprocessing stages, regenerated by step 09.

The main code is Preprocessing/01–09, Training/CNN.py, Training/ViT.py, Training/Hybrid.py, their shared dataset.py, and root app.py. app.py is the only UI Python file.

Raw data, generated datasets, trained output folders and local archives are not distributed in Git. See RUN_PROJECT.md for exactly what to transfer separately. Code-Archive and Training under this documentation folder are historical local material, not active application folders.
